# Submission checklist

- Review `submission/brief.md` and `submission/demo.mp4`; understand and approve their content.
- Describe your own contribution, AI assistance and shared infrastructure accurately.
- Publish an accessible build repository containing code, prompts, README, TEST_LOG.md and preserved experiments.
- Supply the exact generated brief. If you edit it, disclose those edits; the prepared copy is unedited.
- Supply the 2–3 minute video. The prepared walkthrough uses edited real screenshots and a disclosed synthetic voice.
- Put links in each required form field, including a separate video field if present.
- Test evaluator access. Private repo links and localhost links do not automatically provide access.
- Do not upload `.env`, API keys, virtual environments, private notes or local upload folders.
- Submit the actual assessment form before its deadline. This package does not submit it for you.
